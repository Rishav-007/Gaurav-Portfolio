Custom Linux ISO — Autologin & Auto-Root

    
Linux · ISO Remastering · Shell

    
ISO Remaster Pipeline

    
Overview

    
A modified Linux distribution ISO that boots directly into a root session without manual login — designed for rapid lab deployment and repeated testing cycles.

    
Remaster Pipeline

    
mkdir -p iso && sudo mount -o loop distro.iso /mnt
cp -a /mnt/. iso/ && sudo umount /mnt
# edit boot/init config for autologin + root shell
sed -i 's/^ExecStart=.*/ExecStart=-\/sbin\/agetty --autologin root --noclear %I $TERM/' iso/etc/systemd/system/getty.target.wants/getty@tty1.service
xorriso -as mkisofs -o custom.iso \
  -b isolinux/isolinux.bin -c isolinux/boot.cat \
  -no-emul-boot -boot-load-size 4 -boot-info-table iso/

    
Why it helps

    
    
      
  • Eliminates 2-3 minutes of manual login per boot during lab rebuilds
    • 
      
  • Consistent root environment for automation scripts
    • 
      
  • Validated on VirtualBox, VMware, and physical test hardware
    •
